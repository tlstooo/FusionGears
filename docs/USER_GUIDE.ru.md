# FusionGears — инструкция

[English](USER_GUIDE.en.md) · **Русский** · [← к описанию](../README.ru.md)

Окна команд говорят на языке интерфейса Fusion: в русском Fusion — по-русски, в любом другом — по-английски. Чтобы переключить, смените язык Fusion (Настройки → Общие → Язык) и перезапустите его.

## 1. Установка

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте его. Переименуйте папку `FusionGears-main` в **`FusionGears`** — имя папки должно совпадать с именем файла `FusionGears.py`, иначе Fusion её не запустит.
2. В Fusion нажмите **Shift+S** (или **Утилиты → Надстройки → Сценарии и надстройки**). Не путайте с пунктом «Расширенные возможности» — это магазин дополнений.
3. Вкладка **«Надстройки»** → **+** → выберите папку `FusionGears`.
4. Включите переключатель в строке FusionGears. Галочка **«Запускать при старте»** загружает надстройку при каждом запуске Fusion.

После запуска появятся три кнопки:

| Кнопка | Где |
|---|---|
| Шевронная / косозубая шестерня | Solid → Create |
| Коническая шестерня | Solid → Create |
| Проверка зубчатой передачи | Solid → Проверка (Inspect) |

**Обновление.** Замените файлы в папке и перезапустите надстройку: выключите и снова включите переключатель (или «Остановить» → «Запустить»).

## 2. Быстрый старт

1. Откройте новый дизайн.
2. **Solid → Create → Шевронная / косозубая шестерня**.
3. В поле **«Типовой вариант»** выберите, например, «Шеврон 1:2, 3D-печать (m2, 20/40)».
4. Нажмите **OK**. Построятся шестерня, колесо, стойка передачи, два вращательных соединения и связь движения.
5. **Сборка → «Анимация зависимостей подключения»** — пара закрутится. Можно и просто потянуть колесо мышью.

## 3. Цилиндрическое колесо (шевронное, косозубое, прямозубое)

| Поле | Что задаёт |
|---|---|
| Типовой вариант | заполняет окно готовым набором; «Свои параметры» ничего не меняет |
| Тип зуба | Шевронный / Косозубый / Прямозубый |
| Нормальный модуль | модуль в нормальном сечении зуба, мм |
| Число зубьев | зубья этого колеса |
| Угол наклона зуба | угол винтовой линии на делительном цилиндре (для шеврона обычно 25–35°) |
| Направление | Правый / Левый; у сопряжённого колеса направление выбирается противоположным |
| Угол профиля | обычно 20° |
| Ширина венца | полная ширина колеса; у шеврона каждая половина — ширина/2 |
| Диаметр отверстия | 0 — без отверстия |
| Боковой зазор | зазор пары по нормали; каждое колесо утончается на половину. Для FDM-печати 0.1–0.2 мм |
| Создать сопряжённое колесо | строит второе колесо в зацеплении на межосевом расстоянии |
| Зубьев у колеса 2, Отверстие колеса 2 | параметры второго колеса |
| Шарниры и связь движения | стойка, вращательные соединения и связь движения для пары |
| Расчёт | диаметры, торцовый модуль, межосевое расстояние; здесь же сообщения об ошибках |

Шевронное колесо удобно печатать без поддержек, а осевых сил у шеврона нет. Косозубая пара даёт осевую силу — учитывайте это в подшипниках.

## 4. Коническое колесо

| Поле | Что задаёт |
|---|---|
| Линия зуба | Прямой / Косой (тангенциальный) / Спиральный (логарифмический) / Круговой (Gleason) |
| Внешний торцовый модуль | модуль на внешнем (большом) торце, мм |
| Число зубьев / Зубьев у парного колеса | нужны оба: от их отношения зависит угол конуса |
| Межосевой угол | угол между осями валов, обычно 90° |
| Угол наклона зуба (в середине) | для косого, спирального и кругового зуба, обычно 25–35° |
| Направление | у парного колеса — противоположное |
| Радиус резцовой головки (0 — авто) | только для кругового зуба Gleason; 0 — равен среднему конусному расстоянию Rm |
| Ширина венца | длина зуба вдоль образующей; в окне есть подсказка «не больше Re/3» |
| Толщина основания | толщина диска за зубьями |
| Сечений по длине зуба | точность криволинейного зуба (больше — точнее и медленнее) |
| Создать парное колесо | строит второе колесо с общей вершиной конусов |

В блоке «Расчёт» видны угол делительного конуса δ, внешний диаметр, конусное расстояние Re и эквивалентное число зубьев; для криволинейного зуба — угол наклона у носка, в середине и у пятки, для кругового — радиус резцовой головки.

### Какую линию зуба выбрать

| Линия зуба | След зуба на плоском колесе | Угол наклона вдоль зуба |
|---|---|---|
| Прямой | радиальная прямая через вершину | 0 |
| Косой (тангенциальный) | прямая, касательная к окружности вокруг вершины | растёт к носку |
| Спиральный (логарифмический) | логарифмическая спираль | постоянный |
| Круговой (Gleason) | дуга окружности резцовой головки | растёт к пятке, как у колёс Gleason |

Круговой зуб Gleason — обычный выбор для конических колёс с криволинейным зубом. Чем меньше радиус головки, тем сильнее изогнут зуб и тем больше меняется угол наклона: при радиусе, равном Rm, и β = 35° угол идёт примерно от 30° у носка до 40° у пятки. Если головка слишком мала для такой ширины венца, окно скажет об этом и подскажет значение.

## 5. Механизм: соединения и связь движения

Флажок **«Шарниры и связь движения»** (включён по умолчанию при построении пары) создаёт:

- компонент **«Стойка передачи»**, зафиксированный в пространстве;
- **вращательное соединение** каждого колеса со стойкой по его оси. Ось берётся из скрытого эскиза «ось вращения» внутри компонента колеса;
- **связь движения** «Передача z1:z2». Направление выбирается проверкой: шестерня поворачивается на четверть шага, и зубья не должны пересечься.

Как крутить:

- **Сборка → «Анимация зависимостей подключения»** — учитывает связи движения;
- перетаскивание колеса мышью — тоже учитывает связи;
- **«Анимация соединения»** (правая кнопка на соединении) крутит **только одно** соединение, а соседнее колесо стоит. Это поведение Fusion, а не ошибка передачи.

Соединения создаются только в дизайне со сборкой (Assembly или Hybrid). В дизайне типа Part надстройка построит колёса и предупредит, что соединений не будет.

## 6. Проверка зубчатой передачи

**Проверка → «Проверка зубчатой передачи»** анализирует все вращательные соединения и связи движения дизайна, в том числе сделанные вручную:

| Сообщение | Что значит и что делать |
|---|---|
| «связи заставляют вращаться в разные стороны / с разной скоростью» | цепочки связей противоречат друг другу (например, три колеса «треугольником», где все три вместе вращаться не могут). Уберите лишнее колесо или связь |
| «при вращении зубья … врезаются» | у связи неверное направление или передаточное отношение. Откройте связь и переключите «Обратить» (Reverse) или исправьте углы |
| «… пересекаются в текущем положении» | колёса стоят друг в друге — часто это новая пара, построенная в начале координат поверх старой. Передвиньте её |
| «… в зацеплении, но не связаны связью движения» | одно колесо будет крутиться, а соседнее стоять. Добавьте связь движения (Сборка → Связь движения) |
| «Связь … не передаёт вращение» | связь повреждена (смотрите её состояние в браузере) или колесо не может вращаться — например, зафиксировано. Подавленные связи проверка пропускает |

Как это работает: для каждой связи проверка по очереди поворачивает её шарнир на 3°, на это время подавив остальные связи, и измеряет, куда и насколько повернулось второе колесо. Затем она ищет противоречия по всем цепочкам и проверяет пересечения тел. Положения шарниров и состояние связей после проверки восстанавливаются.

После построения пары с соединениями проверка запускается сама и показывает окно, только если нашла проблему.

## 7. Демонстрационный набор

Скрипт `demo/FusionGearsDemo` показывает проверку в действии:

1. Shift+S → вкладка **«Сценарии»** → **+** → папка `demo/FusionGearsDemo` → запустить.
2. Откроются два документа:
   - **исправная передача** — цепочка z15 → z30 → z20 под углом и коническая пара 15:30; проверка: проблем нет;
   - **передача с ошибками** — перевёрнутая связь, колесо z18 в зацеплении без связи и три колеса z21 «треугольником»; проверка находит все три ошибки.
3. В конце скрипт покажет, что нашла проверка. Запустите проверку сами в каждом документе.

### Разбор передачи с ошибками

Запустите анимацию (**Сборка → «Анимация зависимостей подключения»** или потяните большое колесо z30 мышью) и сравните с тем, что сообщает проверка:

| Что видно при анимации | Ошибка | Как исправить |
|---|---|---|
| Крайнее левое колесо **«Лишняя z18 (без связи)»** стоит, хотя касается ведущей z15 | у его шарнира нет связи движения — проверка: «в зацеплении, но не связаны связью движения» | **Сборка → Связь движения**: «Вращение Ведущая z15» и «Вращение Лишняя z18 (без связи)», углы **360°** и **300°** (360 · 15/18), включите обратное направление (Reverse) |
| **«Ведомая z20»** крутится, но в ту же сторону, что и большое z30 — в настоящем механизме зубья бы врезались, а Fusion проводит их друг сквозь друга | связь «Передача 30:20» перевёрнута — проверка: «при вращении зубья … врезаются» | откройте связь «Передача 30:20» и переключите обратное направление (Reverse) |
| Три колеса **«Треугольник A/B/C z21»** не вращаются вместе | в контуре из трёх внешних зацеплений каждому колесу нужно крутиться сразу в обе стороны — проверка: «связи заставляют вращаться в разные стороны» | связью это не исправить: уберите одно из колёс или отодвиньте его так, чтобы оно зацеплялось только с одним соседом, и удалите лишнюю связь |

После первых двух исправлений проверка покажет только «треугольник», а цепочка z18 → z15 → z30 → z20 будет вращаться целиком. Для сравнения откройте вкладку «Исправная передача»: там все колёса крутятся вместе.

Почему в анимации «неправильные» колёса тоже двигаются: Fusion не учитывает касание зубьев, он просто выполняет связи движения. Поэтому перевёрнутая связь выглядит как обычное вращение, а колесо без связи стоит, даже если стоит вплотную к соседу. Ошибки такого рода видны только проверкой.

## 9. Подшипник

Команда **Solid → Create → «Подшипник»** ставит шариковый подшипник стандартного размера.

1. **Место (круговая кромка)** — щёлкните кромку отверстия или вала. Подшипник встанет соосно с ней, торцом на плоскость кромки, и уйдёт внутрь отверстия или вдоль вала (направление берётся по соседней цилиндрической грани). Без выбора подшипник ставится в начало координат по оси Z.
2. **Подобрать размер по кромке** — при выборе кромки надстройка ищет подшипник, у которого внутренний диаметр d или наружный D совпадает с диаметром кромки (допуск 0.3 мм). Если подходит выбранный типоразмер, он остаётся; иначе берётся подходящий из текущей серии, затем из остальных серий того же типа; при нескольких подходящих — ходовой размер (608, 625, 6202…). Например, для отверстия Ø22 мм остаётся 608, а на вал Ø15 мм в серии 62 подберётся 6202.
3. **Перевернуть** и **Смещение вдоль оси** — если подшипник ушёл не в ту сторону или его нужно утопить.
4. **Серия** и **Типоразмер** — радиальные 6xx/MR (миниатюрные, в том числе 608 и 625 для 3D-принтеров), 618 (68xx), 619 (69xx), 60, 62, 63 и упорные 511, 512. Пункты «свои размеры» открывают поля d, D, B для любого размера.
5. **Исполнение**: подробное — наружное и внутреннее кольца с дорожками качения и шарики, по желанию защитные шайбы (2Z); упрощённое — одно тело по габаритам, для больших сборок.
6. **Закрепить на детали** — жёсткое соединение подшипника с деталью, кромку которой вы выбрали: при перемещении детали подшипник едет с ней. Если кромка принадлежит корневому компоненту, подшипник просто фиксируется.

Подшипник строится в своём компоненте «Подшипник 608-2Z» и своей группе на таймлайне; пока окно открыто, виден предварительный просмотр. У упорного подшипника тугое кольцо (по валу, отверстие d) лежит на кромке, свободное (в корпус, наружный диаметр D) — сверху.

Присоединительные размеры d × D × B (H) взяты по ISO 15 и ISO 104. Диаметр и число шариков, глубина дорожек — приближённые пропорции, а не данные производителя; сепаратор не моделируется.

## 10. Советы по 3D-печати

- Боковой зазор 0.1–0.2 мм для FDM, 0.05 мм и меньше для фотополимера.
- Не берите меньше 14–15 зубьев: без смещения профиля маленькие колёса подрезаются.
- Модуль от 1 мм для FDM-сопла 0.4 мм; на модуле 0.5 зубья получаются на пределе.
- Шевронные колёса печатаются лучше косозубых: нет нависаний, нет осевой силы.

## 11. Если что-то не так

| Признак | Причина |
|---|---|
| Кнопок нет | надстройка не запущена или папка называется не `FusionGears` |
| «Заострённый зуб» / «зубья пересекаются у основания» | слишком мало зубьев или слишком большой угол — увеличьте число зубьев |
| «Ширина венца больше …» | для конических колёс уменьшите ширину венца (рекомендуется ≤ Re/3) |
| «Радиус резцовой головки … слишком мал» | увеличьте радиус головки Gleason или задайте 0 |
| Соседнее колесо не крутится | использована «Анимация соединения»; используйте «Анимация зависимостей подключения» |
| Колёса крутятся в одну сторону | связь перевёрнута — запустите «Проверку зубчатой передачи», она укажет связь |
| Подшипник ушёл не в ту сторону | включите «Перевернуть» или задайте смещение |
| Размер не подобрался по кромке | диаметр кромки отличается от d и D больше чем на 0.3 мм или серия другого типа — выберите типоразмер вручную |
| Окна не на том языке | язык берётся из Fusion: смените его в настройках и перезапустите Fusion |
| Ошибка «a command definition with that id already exists» | надстройку перезапустили несколько раз за сессию; перезапустите Fusion |
